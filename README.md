# 수원 출장마사지 · 홈타이 지역 SEO 사이트

경기도 수원시 방문형 마사지·홈타이 정보를 4개 행정구 / 대표 행정동 / 역세권 / 생활권 기준으로
안내하는 정적 지역 SEO 사이트입니다.

- 상호: **바로 GO**
- 전화예약: **0508-202-4719**
- 핵심 키워드: 출장마사지 · 보조 키워드: 홈타이

## 구성 (총 63 페이지)

| 구분 | 수 |
|------|----|
| 메인 | 1 |
| 행정구 (장안·권선·팔달·영통) | 4 |
| 대표 행정동 | 29 |
| 역세권 (지하철·철도역) | 14 |
| 생활권·주요 거점 | 10 |
| 기타 (예약/이용안내/가이드/개인정보/고객센터) | 5 |

번호 행정동(정자1~3동, 세류1~3동, 매탄1~4동, 영통1~3동 등)은 대표 동으로 통합하고,
환승역(수원역 등)은 노선별로 쪼개지 않고 1 URL로 운영해 중복 콘텐츠를 방지합니다.

## SEO 적용 사항

- 모든 페이지 메타 디스크립션 **80자 이내** (네이버 기준)
- 구조화 데이터: `WebPage` / `BreadcrumbList` / `Organization` (오프라인 주소가 없는 방문형이라 `LocalBusiness` 미사용)
- 선호 썸네일 지정: `og:image` + schema `primaryImageOfPage` (`/assets/og-image.svg`)
- canonical, Open Graph, Twitter Card, breadcrumb, 내부링크 허브 구조
- `sitemap.xml`, `robots.txt`, 모바일 우선·경량 CSS(무 JS)

## 빌드

```bash
python3 build.py
```

`build.py`의 페이지 데이터와 본문을 수정한 뒤 다시 실행하면 전체 HTML이 재생성됩니다.
배포 도메인은 `build.py` 상단의 `SITE_URL` 값을 실제 도메인으로 교체하세요.

## 배포 (GitHub Pages)

저장소 루트를 그대로 정적 호스팅하면 됩니다. 루트 `index.html`은 `/suwon-chuljangmassage/`로
이동하는 메인 진입점입니다. `.nojekyll` 파일로 Jekyll 처리를 비활성화합니다.

## 운영 원칙

방문형 지역 정보 안내 사이트로, 불법·선정적 서비스를 제공하거나 알선하지 않습니다.
과장·허위 후기, 과도한 할인 문구를 사용하지 않으며 방문 지역·예약 시간·이동비·취소 기준·개인정보 처리 기준을 명확히 안내합니다.
